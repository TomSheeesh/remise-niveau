Module 2 – SQL pour l’analyse de données
Objectif général

Savoir extraire et manipuler des données avec SQL afin de répondre à des questions métiers.

1️⃣ Requêtes de base : SELECT, WHERE
Notions

SELECT : choisir les colonnes à afficher.

FROM : indiquer la table.

WHERE : filtrer les lignes selon des conditions.

Exemple
SELECT first_name, last_name, age
FROM customers
WHERE country = 'France';

Exercice pratique

Crée une table customers avec des colonnes id, first_name, last_name, country, age.

Écris une requête pour afficher tous les clients de plus de 30 ans.

Écris une requête pour afficher uniquement les clients vivant en France.

2️⃣ Fonctions d’agrégation et GROUP BY
Notions

COUNT, SUM, AVG, MAX, MIN : calculs statistiques sur des colonnes.

GROUP BY : regrouper les résultats par une colonne.

Exemple
SELECT country, COUNT(*) AS nb_clients
FROM customers
GROUP BY country;

Exercice pratique

Combien de clients par pays ?

Quel est l’âge moyen des clients par pays ?

Affiche les 5 pays avec le plus de clients.

3️⃣ JOIN : combiner plusieurs tables
Notions

INNER JOIN : ne conserve que les lignes présentes dans les deux tables.

LEFT JOIN : conserve toutes les lignes de la table de gauche, même si pas de correspondance à droite.

Exemple
SELECT c.first_name, c.last_name, o.order_date
FROM customers c
INNER JOIN orders o ON c.id = o.customer_id;

Exercice pratique

Crée une table orders avec colonnes id, customer_id, order_date, amount.

Affiche tous les clients avec leurs commandes.

Affiche tous les clients, même ceux sans commande.

4️⃣ Sous-requêtes et filtres avancés
Notions

Sous-requête dans WHERE : filtrer selon un calcul ou une liste provenant d’une autre requête.

Exemple
SELECT first_name, last_name
FROM customers
WHERE id IN (
    SELECT customer_id
    FROM orders
    WHERE amount > 100
);

Exercice pratique

Quels clients ont passé au moins une commande de plus de 100€ ?

Quels clients ont passé leur dernière commande avant 2023 ?

5️⃣ Optimisation de requêtes (initiation)
Notions

Utiliser des filtres dès le début (WHERE) pour limiter le volume de données.

Préférer JOIN sur les colonnes indexées.

Éviter les SELECT * quand ce n’est pas nécessaire.

Exercice pratique

Affiche les 10 commandes les plus récentes pour un client spécifique.

Affiche le total des ventes par mois, trié par montant décroissant.

6️⃣ Cas pratique complet
Étapes

Crée une base SQLite locale et importe un dataset (ex : customers.csv et orders.csv).

Réponds aux questions suivantes avec SQL :

Quels sont les 10 clients les plus actifs (plus de commandes) ?

Quel est le chiffre d’affaires total par pays ?

Quels clients n’ont jamais passé de commande ?
